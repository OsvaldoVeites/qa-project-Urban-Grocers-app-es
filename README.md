# Proyecto Urban Grocers 
# Pruebas para el crear un nuevo kit en un usuario en particular.
- Necesitas tener instalados los paquetes pytest y request para ejecutar las pruebas.
- Ejecuta todas las pruebas con el comando pytest.
- Crea las pruebas de acuerdo a las listas de comprobacion.
- Diseña las pruebas deacuerdo a la lista de comprobacion.
- Todas las rutas estan almacenadas en configuration.py
- Todas las solicitudes se alamcenan en sender_stand_request.py
- Recuerda el token de autenticación (authToken), asegurando pasar también el encabezado Autorization.
- Para el cuerpo de las solicitudes utiliza la lista de comprobacion
- Los cuerpos de las solicitudes POST es en cuentran en el archivo data.py
